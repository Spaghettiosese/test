# Graphics overhaul — shared brief (all art/UI agents read this)

Goal: move LAST BELL's look much closer to Disco Elysium's painted isometric style, while staying original:
oil-paint / gouache texture with visible directional brushwork, painterly not vector; realistic proportions; cinematic
warm/cool lighting (hot orange practical lights vs teal/blue ambient), dappled light, deep soft shadows, atmospheric
haze, restrained desaturated palettes with saturated accents, heavy grain + vignette; readable silhouettes; the thin bright
green interactable outline. Portraits stay PIXEL ART (the user's request) but much higher fidelity.

Ownership (edit ONLY your files; js/art.js is generated by `bash tools/build-art.sh` — never hand-edit it):
- ENV/LIGHT agent: tools/artsrc/a_core.js, b_world.js, e_scene.js, tools/build-art.sh
- CHARS agent: tools/artsrc/d_chars.js
- PROPS agent: tools/artsrc/c_props1.js, c_props2.js, c_props3.js
- PORTRAIT agent: tools/artsrc/f_portrait.js, f_items.js
- SCENES agent: tools/artsrc/g_scenes.js, g_scenes2.js
- UI agent: css/style.css, index.html (markup only), presentation code in js/ui.js (no game-logic changes)
Need a helper from someone else's file? Put a private copy (prefixed with your area, e.g. `ch_`) in YOUR file. Do not
rename/remove any function another module calls. Keep all public `Art.*` API in h_export.js unchanged (nobody edits it).

Contracts between modules (do not break):
- Sprite object from getFigure/figureNow: `{c, w, h, ax, ay, hang?}`; drawn in e_scene as
  `drawImage(spr.c, -ax/SS, -ay/SS, w/SS, h/SS)` at the feet point. SS is the supersample factor (defined in a_core).
- Props: functions in c_props*.js keyed by prop type, called by e_scene's scene builder with the same signature as now.
- Scene renderer API: `Art.getRenderer(loc).draw(ctx, view, dyn)`; view/dyn as in docs/CONTRACT.md + ADDENDUM.
- Perf budget: ≤ 16 ms/frame at 1280×720 in software-rendered headless Chromium for typical rooms; first bake ≤ 900 ms
  per location (cache aggressively); must still work on phones (devicePixelRatio ≤ 2).

Testing: build with `bash tools/build-art.sh`. Use headless Chromium via Playwright (`require('/opt/node-tools/node_modules/playwright')`,
executable `/opt/pw-browsers/chromium-*/chrome-linux/chrome`; never run `playwright install`). Do not edit tools/art-test.html;
make your own harness page in your scratch folder that loads files by absolute `file:///home/user/test/lastbell/...` paths,
or drive `index.html?debug` (exposes `window.G`; `G.teleport('canteen')`, etc). Save screenshots in
/tmp/claude-0/-home-user-test/3fe2d995-7f9f-5f09-b408-2aad6ad25007/scratchpad/<your-area>/ and LOOK at them; iterate.
Other agents rebuild art.js concurrently; if your screenshot shows something odd in another agent's area, ignore it.
Do not git commit. Final check: `node --check js/art.js`, then `node tools/test-game.js` passes.
